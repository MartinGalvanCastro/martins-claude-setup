# AGENTS.md

This repo is a portable setup for coding agents: expert subagents, the `/ship` workflow (plan, plan review, implement, QA, merge) and a plugin list. It supports Claude Code, OpenCode and Codex, on Windows, Linux and macOS.

## If the user asks you to install it

1. Read `README.md` for what it contains and `INSTALL.md` for the full list of what to install and configure.
2. Pick the target for the tool you are running in: `claude`, `opencode` or `codex`.
3. Follow `INSTALL.md` in order. It tells you to run `python install.py --target <target>` (`python3` on macOS and Linux, `python` or `py` on Windows; `--no-plugins` skips plugin downloads, Claude only). That script copies only the `/ship` command and the `grill-me` skill and merges the plugin settings.
4. Create the agents yourself from the list in `INSTALL.md`, in your tool's format: 9 in Claude Code (4 more come from plugins or the tool itself), all 13 elsewhere. There are no agent files in this repo on purpose.
5. Restart the tool, verify as `INSTALL.md` says, and report what was installed, what was skipped and which backups were made.

## Rules

- Back up before overwriting. `install.py` does this for every file it changes.
- Do not change `model` or `statusLine` in the user's settings.
- Do not commit, push or change other repos.
- If a plugin or marketplace is blocked by company policy, report it. Do not work around it.
- Never add secrets to this repo.

## Editing this repo

- The agents are defined only in `INSTALL.md`, section 5. Edit them there.
- `claude/commands/` and `claude/skills/` are the source of truth for `/ship` and `grill-me`. The OpenCode and Codex versions are generated by `install.py`: edit `claude/`, then re-run the installer.
- When creating OpenCode agents, take `model:` from `models.json` by tier (`opus`, `sonnet`, `haiku`). It is set for OpenCode Go (`opencode-go/...`). An empty value means omit `model:` so the agent inherits the session model. Run `/models` in OpenCode to confirm the IDs the account can use.
- Keep docs in Spanish and the files agents read (agents, commands, skills) in English.

## Known limits

- Codex has no stable per-agent file format here, so each agent is created as a skill holding its role, with no model tiering. Codex runs the command as `/prompts:ship`.
- The OpenCode and Codex formats were written from memory and not tested. Check the paths `install.py` prints against the tool's current docs.
- `/ship` was not tested on CodeCommit or Bitbucket.
